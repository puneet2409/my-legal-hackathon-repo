Plain English Summary

Converts dense legal jargon into clear obligations, key dates, financial penalties, and takeaway bullet points.

🚨

Clause Risk Matrix

Spots predatory clauses like auto-renewals, unilateral liability, and hidden fees in a structured risk assessment table.

⚖️

Contract Comparison

Compares initial drafts vs. counter-party revisions to surface newly added, removed, or subtly modified terms.

🚀 Quickstart (Run Locally in 3 Steps)

# 1. Clone repository
git clone https://github.com/puneet2409/my-legal-hackathon-repo.git
cd my-legal-hackathon-repo

# 2. Install dependencies
pip install -r requirements.txt

# 3. Add Gemini API key to .env and launch
echo GEMINI_API_KEY=your_key_here > .env
streamlit run app.py
